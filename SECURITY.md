# Security Policy

## Supported versions

This is an early open-source browser game. Security fixes are applied to the latest release line only.

| Version | Supported |
| --- | --- |
| `0.1.x` | Yes |

## Reporting a vulnerability

Please do not open a public issue for a potentially exploitable vulnerability.

Report privately through [GitHub Security Advisories](https://github.com/itline/persian-isles-mini-golf/security/advisories) when available. If that channel is unavailable, contact the maintainer through the [itline GitHub profile](https://github.com/itline).

Include:

- A short description and impact.
- Reproduction steps or a minimal proof of concept.
- Affected version, browser and operating system.
- Any suggested mitigation.

Do not include passwords, access tokens, private company data or other secrets in an issue or pull request. Never commit `.env` files or credentials.

The project has no required backend, account, API key or server-side score service in this release. Third-party dependency notices and audit records are included in the repository.
